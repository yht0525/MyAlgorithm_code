# Main Stream Pool —— 算法学习代码库

按主题分模块整理的算法学习代码集合，覆盖 **搜索、数据结构、动态规划、图论、数论、组合数学、线性代数** 等竞赛/课程核心内容。每个模块尽量遵循「模板 + 例题」的组织方式：先看模板理解套路，再用例题验证和拓展。

- 语言：C++（C++11）
- 规模：125 个 `.cpp` 源文件 + 2 篇笔记
- 依赖：无第三方库，标准库即可编译运行

## 编译与运行

绝大多数文件都是**单文件、可独立编译**的完整程序，从标准输入读数据、向标准输出打印结果。

### 命令行（g++ / MinGW）

```bash
g++ -std=c++11 -O2 "路径/文件名.cpp" -o main
./main
```

例如：

```bash
cd Main_stream_pool/4.Graph_theory/4.第四模块：单源最短路
g++ -std=c++11 -O2 "dijkstra堆优化版.cpp" -o dijkstra
./dijkstra < input.txt
```

> Windows 下如果使用 Git Bash，可执行文件名为 `main.exe`，直接运行 `./main.exe` 即可。

### VS Code

1. 安装 C/C++ 扩展；
2. 打开任意 `.cpp` 文件，按 `F5` 或使用 Code Runner 运行；
3. 建议在编译参数中加入 `-std=c++11`（部分代码用到了 `auto`、范围 for、初始化列表等特性）。

### 输入格式

各文件按题目要求读取输入，没有统一格式。作为模板使用的文件通常在第一行读入规模（如 `n`、`n m s`），随后读入具体数据；练习文件请结合文件名对应的原题理解输入。

## 代码约定

- **单文件**：每个 `.cpp` 自带 `main()`，可直接编译运行（`Higher_level/kmp算法/next数组kmp模拟.cpp` 为纯模拟 / 片段，不含 `main`）。
- **下标习惯**：多数实现采用 **1-indexed**，全局数组大小以 `const int N = ...` 声明。
- **命名习惯**：`1.模板.cpp` / `模板.cpp` 表示该知识点的标准写法；其余文件以题目名命名。
- **讲解注释**：关键步骤、易错点（如并查集路径压缩、边界处理）以行内注释标出。
- **兼容性**：代码以 C++11 为准，未使用第三方库。

## 建议学习顺序

```
搜索  →  数据结构  →  动态规划  →  图论  →  数论  →  组合数学  →  线性代数  →  进阶
```

1. **搜索**打基础：先掌握 DFS 枚举与回溯，再学剪枝、记忆化，最后用 BFS 处理最短路 / 状态搜索。
2. **数据结构**与搜索结合最紧：单调栈 / 队列解决滑动窗口类问题，并查集用于连通性维护。
3. **动态规划**是主体内容：按「基础 → 线性 → 经典 → 背包 → 区间」推进。
4. **图论**与**数论**可按需穿插，两者都以模板为主，建议先背熟模板再做题。
5. **组合数学**与**线性代数**偏工具性，用到时回查即可。
