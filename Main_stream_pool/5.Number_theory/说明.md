<约数>
(1):求一个数的所有约数

    ex: int n;
        int cnt;
        for(int i=1;i<=n/i;i++)
        {
            if(n % i == 0)
            {
                d[++cnt] = i;
                if(i != x/i)d[++cnt] = x/i;
            }
        }

(2):求[1,n]之间每个数的约数个数

    ex: (正男则反,判断1~n)
        vector<int> d[N];

        for(int i=1;i<=n;i++)
        {
            for(int j=1;j*i<=n;j++)
            {
                d[i*j].push_back(i);
            }
        }

(3):约数个数定理:对于N: N = p1^a1 * p2^a2 * p3^a3 *...

    有约数个数 = (a1+1) * (a2+1) *...

    所以求约数有两种方式：
    [1]:枚举一个数的全部约数
    [2]:对一个数进行分解质因数，利用约数个数公式

(4):求解约数之和:对于N: N = p1^a1 * p2^a2 * p3^a3 *...

    有约数之和 = (1+p1^1+p1^2+...) * (1+p2^1+p2^2+...) * ...


(5):欧拉函数：计算从【1，n】与某一个数互质数的个数
